# web-sales-demos
Web制作営業用デモサイト

## デモサイトURL公開ルール（最短運用）

完成済みのセクション画像をURL公開する場合は、以下を標準手順とする。

1. 既存の会社別フォルダ構成を流用する。
2. 完成済み画像は原則として再生成・再圧縮・複数品質比較をしない。
3. 画像サイズが統一済みなら、そのまま使用する。
4. 会社ごとに `01-hero` 〜 `08-contact` の8画像と `index.html` を配置する。
5. `index.html` は既存テンプレートを流用し、画像を縦に連結表示するだけの最小構成にする。
6. GitHub Contents APIの確認は必要最小限にし、同じファイルや設定を何度も再確認しない。
7. 公開処理は「画像配置 → index.html作成 → 公開URL確認」まで一気に進める。
8. 明確な不具合がない限り、途中で画像最適化やデザイン再調整を挟まない。
9. 目標は、素材が完成済みならURL公開作業を約1分で完了できる運用にする。
